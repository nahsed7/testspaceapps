# NASA Space Apps 2026 — LAGRANGE_NEXUS 🚀

Repository for the LAGRANGE_NEXUS team's preparation and prototypes for NASA Space Apps 2026.

## Challenges

This repository contains preparation work for four candidate challenges:

1. **Flame in Freefall**
2. **Dancing with the SARs**
3. **CLPs**
4. **SPHEREx**

The goal is to understand the scientific problems, experiment with public/previous datasets, develop reusable computational pipelines, and build prototypes that can be adapted during the hackathon.
